# Lara Seline · site

Site da DJ Lara Seline (Electronic Music Artist): bio, identidade sonora, vídeos, galeria, marcas e a aba **Material** com download de todas as fotos e vídeos.

- Abrir no computador: dois cliques em `index.html`.
- Publicar no GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

Estrutura: `index.html` (página), `img/` (fotos para a página), `dl/` (fotos em alta para download), `vid/` (vídeos MP4 e capas).
